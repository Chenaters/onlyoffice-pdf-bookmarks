# Add PDF Bookmarks plugin

## What the plugin does

PDF Bookmarks adds a persistent left-side navigation panel to the ONLYOFFICE
PDF editor. Users can save named page markers, jump back with one click, rename
or delete bookmarks, and keep separate lists for separate PDFs.

## Compatibility

- ONLYOFFICE 9.4.0 or later
- PDF editor
- Viewer and edit modes
- Light, dark, and contrast-dark themes

## Privacy and dependencies

- Works offline.
- Has no accounts, API keys, analytics, or network requests.
- Stores bookmark data in the editor's local storage.
- Does not modify or write bookmarks into the PDF file.

## Verification

- Automated tests pass.
- The `.plugin` archive installs manually in ONLYOFFICE Desktop Editors.
- Multi-scale icons and marketplace screenshots are included.
