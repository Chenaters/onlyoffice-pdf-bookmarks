# PDF Bookmarks launch kit

## Tagline

Save your place in long PDFs without changing the file.

## Marketplace description

PDF Bookmarks adds private, persistent page markers to PDFs in ONLYOFFICE.
Save a named page, return to it with one click, and manage a separate list for
every PDF. The plugin works offline and leaves the original PDF unchanged.

Requires ONLYOFFICE 9.4 or later. Bookmarks are stored locally on this device
and are not embedded into the PDF outline.

## Community forum post

I made an open-source PDF Bookmarks plugin for ONLYOFFICE 9.4+. It covers the
core workflow requested here: save named page markers, jump back with one
click, rename or delete them, and keep them after reopening the PDF.

The current release stores bookmarks locally and does not modify the PDF
outline. Nesting, colors, and drag-and-drop ordering are not included yet, so I
would especially value feedback on which of those should come next.

Repository and download:
https://github.com/Chenaters/onlyoffice-pdf-bookmarks

I built PDF Bookmarks, an open-source plugin for ONLYOFFICE 9.4+ that lets
people save and revisit named pages in long PDFs. It works offline, stores data

The plugin responds to an active community request for PDF bookmarking. I have
